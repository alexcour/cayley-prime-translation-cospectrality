# Cospectrality of a structured three-element support under prime cyclic translation

**Review status: PUBLIC REVIEW / 0.1.x. Current package: 0.1.3-review (2026-10-06). This is an unstable review snapshot, not a stable scientific release.**

This repository is public for external review and provides a dated, inspectable record of the current work on the structured support-translation family

`T = {(kappa,0),(kappa,c),(kappa',0)}` and `T+ = T + (0,c)`

in `H x C_p`, where `H` is a finite abelian group generated by `kappa,kappa'` and `p` is an odd prime.

Public visibility at version `0.1.x` is intended to invite checking. It does **not** close the mathematical review gate, the priority/antecedence audit, or the reproducibility/provenance review.

## Current theorem status (E)

- `p >= 5`: internal witness 10A6 states cospectrality iff a homomorphism `h:H->F_p` exists with `h(kappa')=1` and `h(kappa) in {1,2}`, iff an explicit group automorphism maps `T` to `T+`.
- `p = 3`: internal witness 10C3 states a beta-symmetry criterion without 3-torsion and the `h` criterion in the 3-torsion regime.
- Cyclic specialization: internal witness 10B1 states injectivity of `mu -> Spec(T_mu)` for even `k` with `3` not dividing `k`.

These are the current internal E-status claims. Independent human mathematical review remains open.

## Priority / antecedence status (N)

**N = NON AUDITEE** for the general classification claims and related mechanisms unless a narrower item is explicitly marked as already antecedent.

The 12-vertex circulant example is already antecedent: equivalent examples appear in work of Julia Brown and Katja Monius. Brown also overlaps with an infinite cyclic subfamily. Primary-source comparison remains open for Meng (1998), Huang-Chang (2001), and the Monius 2020 article.
