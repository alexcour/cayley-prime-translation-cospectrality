# Notation

Public notation should be normalized before release.

Core family:

- `H`: finite abelian group generated by two distinct elements `kappa, kappa'`.
- `p`: odd prime.
- `c`: generator of `C_p`.
- `T = {(kappa,0),(kappa,c),(kappa',0)}`.
- `T+ = T + (0,c)`.

Staging 0.1.1-dev: the public-facing p=3 theorem now uses the unambiguous notation `3∣|H|`. The original Drive witness is preserved under `proofs/original_witnesses/` for provenance. Independent review must still confirm the theorem scope and downstream use.
