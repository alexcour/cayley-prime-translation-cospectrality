# E / N / Q doctrine

- E = truth/proof status in the declared mathematical scope.
- N = priority / antecedence status.
- Q = documentary quality, reproducibility, source availability, and independent review.

`E != N != Q`.

A proved result does not establish priority. A negative literature search is not proof of priority. A missing historical file does not by itself refute a theorem, but it can reduce documentary provenance quality.
